# v0.24 出撃 / 生還後の安全拠点

## 期待するゲームループ
- ゲーム開始時だけ職業を選択する。生還後もその職業・名前・外見を維持する。
- WAVE 3以降のクリア時、**生還** を選ぶと冒険で獲得した装備は倉庫へ、所持Gは金庫へ保存される。
- 生還後は職業選択画面ではなく拠点の安全区域に戻る。WAVE0（活動停止）、戦闘用レベルと強化はリセット。
- 畑の成長状態、種、収穫物、料理、ちゅぶらの装備・なかよし度は維持し、拠点で引き続き活動できる。
- 倉庫は生還後すぐ開ける。保存した装備を取り出したり、バッグから戻したりできる。
- 好きなタイミングで **出撃ボタン** をクリック、または **Gキー** で出撃。WAVE1から再スタートする。
- WAVE中に勝手に安全拠点に戻らない。WAVE3以降のクリアで再び生還か出撃（続行）を選ぶ。

## 手動テスト
1. 忍者など戦士以外の職業を選び、WAVE3までクリアする。
2. 生還を押す。直前に獲得した装備・冒険Gの保存が成功したことを確かめる。
3. 職業選択画面が表示されず、忍者の姿のまま拠点に戻ることを確認する。
4. 倉庫を開き、獲得した武器を取り出して装備し、また収納できる。
5. 畑の作物が生還前の成長段階のままであることを確認。収穫し、料理する。
6. ちゅぶらのなかよし度・装備を確認し、ミントやスロットなどと拠点で交流する。
7. 何分放置しても敵やWAVEが始まらないことを確認する。
8. 出撃ボタンかGキーを押す。選択した職業は変わらずWAVE1から始まり、拠点で持ち出した装備は危険にさらされる。
9. WAVE3以降で「出撃（続行）」を選び、強化3択を選ぶと次WAVEへ進める。
10. 画面に「ALL IN」が残っていないことを確認する（内部コード名は維持）。

## 自動テスト
`tests/test_safe_hub_flow.gd` をCIが実行する。同じ職業、農作物・種・ちゅぶらのなかよし度維持、拠点タイマー停止、手動出撃の遷移を検証。
金庫と倉庫の永続保存自体はユーザーの実データに触れないよう、このテスト内で書き込まず手動確認対象としている。
