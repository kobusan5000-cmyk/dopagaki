# DOPAGAKI v0.25 — 2D探索脱出型 ゲーム仕様

## 目的
今後のオンラインPvPvEゲームに向け、ソロで遊べる探索／戦闘／物資回収／脱出の基礎を実装する。**PvP、マルチプレイ、別インスタンスマップ、クラフトはまだ未実装**。

## 新しいゲームループ
1. 初回のみ職業を選択。選択後は安全拠点で畑・料理・倉庫・商人・ペットなどを自由に楽しむ。
2. 拠点の「探索へ出撃」ボタンまたはGキーを押すと同じフィールドの探索モードを開始。WAVEクリア待ちや時間制限はない。
3. ミニマップでは黄の四角＝物資、青の丸＝脱出装置、黄ひし形＝拠点。
4. 10か所のコンテナに近づき[E]で回収。初期バッグ容量は素材12個（既存の装備バッグ5枠とは別）。コンテナ危険度によりスクラップ・電力コア・古代結晶・G・レア装備の入手を振り分ける。
5. まだ探索するか、近くの青い脱出装置に向かうかを自分で決める。
6. 脱出装置で[E]を押し、半径100以内に12秒間留まる。待機中も敵に攻撃される。離れるとキャンセル。
7. 脱出成功後は装備、G、探索素材がそれぞれ保管され、現在の職業で安全拠点に戻る。再びGキーで出撃できる。
8. 死亡時はRキーで同じ職業の拠点に戻るが、今回の冒険から持ち出した装備・G・素材はロスト。倉庫に保存済みのものは維持。

## 実装範囲
- `scripts/extraction_rules.gd`: コンテナ・脱出地点座標、12個の素材容量、12秒の脱出操作、素材の出現傾向。
- `scripts/main.gd`: 通常出撃を探索モードへ切替、探索コンテナ／脱出／UI／素材永続保存。
- `user://dopagaki_stored_materials_v025.json`: 保存された素材3種類の個数。既存の `user://dopagaki_stash_v1.json` や金庫Gファイルは変更しない。
- `tests/test_extraction_flow.gd`: Godotで出撃、コンテナ、素材、脱出装置の起動・キャンセルと拠点へ戻る挙動を検証。
- 既存の `tests/test_safe_hub_flow.gd` の出撃条件を探索モードに合わせて更新。

## 実際にプレイして確認すること
1. 職業を選んだ後、自動で敵WAVEが始まらず拠点にいる。
2. Gキーで出撃し、マップで黄色い物資マーカーと青い脱出マーカーが見える。
3. コンテナに近づいてEキーで素材とGを回収。探索済みコンテナは二度取れない。
4. 12個の素材上限を超えて回収できない。
5. 高危険度コンテナでレア装備を入手できる場合がある。
6. 脱出装置をEキーで起動し、離れると失敗、戻って再起動可能。
7. 12秒守ると脱出成功、同じ職業の安全拠点へ帰還する。
8. 拠点の倉庫で装備と保管素材を確認。ゲームを再起動しても保管済みデータが残る。
9. 出撃して死亡した場合、手持ちだけ失い、金庫・倉庫の保存済みデータは残る。
10. 農業・料理・ミント・ちゅぶら・武器商人など既存の拠点遊びが壊れていない。
