# 開発者向け:ファイルの入れ方(Git のコマンドは不要です)

## 毎回の流れ

1. **必ず最新のファイルから始める**
   このページ(リポジトリのトップ)の緑の **Code** ボタン → **Download ZIP** を押し、展開します。
   ※ 自分の手元の古いフォルダを使うと、他の人の修正を消してしまいます。
2. Godot で開いて、いつも通り編集します。
3. 変更が終わったら、`CHANGELOG.txt` の**一番上**に今回の変更を書きます(下の「書き方」参照)。
4. このページ(リポジトリのトップ)で **Add file → Upload files** を押します。
5. 展開したフォルダの**中身**(`project.godot`、`scripts`、`scenes` など)を、ブラウザにドラッグ&ドロップします。
   - **フォルダごと**ではなく、**中身**を入れてください。`project.godot` がトップに見える形が正しいです。
   - `.godot` フォルダは入れないでください(自動で作られるキャッシュです)。
6. 下の **Commit changes** を押します。
7. 約2〜3分で、自動で新しい版ができます。**Actions** タブで進み具合を見られます(緑のチェックなら成功)。

## CHANGELOG.txt の書き方

一番上に、新しい変更を書き、**空行を1行**入れてから前の内容を続けます。
一番上の塊(最初の空行まで)が、テスターの画面の「更新内容」に出ます。

```
DOPAGAKI v0.9
- ボスの体力を調整
- 畑の成長を速くした

DOPAGAKI v0.8 fix1
- (前の内容)
```

## 注意

- 失敗(赤い×)になったら、Actions タブでそのビルドをクリックすると理由が出ます。
  - 「project.godot が見つからない」→ フォルダごとアップロードしています。中身を入れ直してください。
- 削除したファイルは、この方法では消えません。消したい時は、リポジトリ上でそのファイルを開き、右上の「…」→ **Delete file** を使います。
- 2人が同時に同じファイルを編集すると、後から入れた方で上書きされます。**編集する前に相手に声をかけてください。**
