# テスター向け

## はじめて使うとき(1回だけ)

1. このリポジトリの **Releases**(右側)を開き、一番上の版から **DOPAGAKI_Launcher.exe** をダウンロードします。
2. 好きなフォルダに置いて、ダブルクリックで起動します。
   - Windows の青い警告が出たら「詳細情報」→「実行」を押します(署名がないための表示です)。

## 毎回

- **ランチャーを起動するだけ**です。最新版が自動でダウンロードされます。
- 画面に「更新内容」が出ます。**PLAY** を押すとゲームが始まります。
- 問題が出たら **REPORT BUG** → 内容を書いて **CREATE REPORT**。
  メールの下書きが開きます(開かないときは、開いたフォルダのファイルを開発者に送ってください)。
- 新しい版で動かなくなったら、画面下の「前の版で遊ぶ」で前の版に戻せます。

## ランチャー自体も自動で最新になります
ランチャーを作り直したときは、次に起動したときに自動で新しい版へ入れ替わり、自動で再起動します。ダウンロードし直す必要はありません。
