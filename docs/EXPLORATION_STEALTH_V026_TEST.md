# v0.26 警戒と静かな脱出 — テストガイド

## 変更の狙い
ARC Raidersに着想を得た「危険を避けて探索し、欲張った分を無事に持ち帰る」2D独自版。キャラクターや世界観はDOPAGAKIオリジナルのまま。

## 遊び方
1. 拠点から[G]で出撃する。通常の敵は高価なコンテナ付近を巡回し、最初から全員が追いかけてはこない。
2. [SHIFT]で静かに歩く。通常より遅くなる代わりに、約135px以内に近づくまで発見されにくい。通常移動なら約330pxで発見される。
3. 攻撃すると約600px以内に発砲音が伝わり、敵が警戒する。物資コンテナ開封時も周辺約290～420pxが警戒する。発見された敵は一定時間追跡する。
4. 2つの通常脱出地点のどちらかで[E]。大きな警報音に相当する通知と増援最大3体。12秒間、脱出範囲から出ずに守り抜く。
5. もう一つの方法は隠し脱出路（690,1080）。探索中にスクラップ×2＋電力コア×1を拾い、隠し脱出路で[E]を押す。周囲への警報・増援なしで4秒後に脱出。
6. 隠し脱出路用素材は脱出成功時にだけ消費する。失敗や途中中断で費用を取られない。
7. 生還すれば残った素材・装備・Gは拠点に保存。死亡すると未確保品を失う。

## 注意点
- 敵の発見判定は2D上の**距離と騒音**であり、壁による視線遮断・地形を使った本格ステルスはまだない。
- プレイヤー同士のPvP/マルチプレイはまだ実装していない。
- 強い相手から「隠れる」「遠回りする」「戦って突破する」の選択肢を増やす初期実装。
- 自動テストは素材コスト、騒音の警戒、巡回/発見判定、隠し脱出の始動・範囲外中断を確認する。
- 実際の敵との戦闘・12秒脱出成功・保存ファイル復旧・UIの見やすさはWindows実機で検証する。

## 手動テスト
- 出撃直後、敵がすぐに全マップから追跡してこないこと。
- SHIFTで警戒範囲に近づいても通常移動より気づかれにくいこと。
- 距離の近い敵を残して発砲すると、周囲が近づいてくること。
- コンテナで[E]を押して素材獲得と周辺警戒通知を確認すること。
- 通常脱出起動で敵3体まで増援が来ること。脱出範囲外に出るとタイマーがキャンセルされること。
- 静かな脱出路では素材不足を通知し、素材がある場合は4秒カウントダウンへ。脱出成功で必要素材だけ消費し残りを倉庫へ。
- 既存のミント・ちゅぶら・農業・忍者・武器の装備・倉庫/金庫保存が正常なこと。
