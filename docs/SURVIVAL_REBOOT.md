# DOPAGAKI — DayZ型サバイバルへの根本転換

更新日: 2026-11-03

## 新しいゲームの目的
「敵を倒してWAVEをクリアし、脱出する」ではなく、**オープンワールドで生存すること自体**を目的にする。探索・資源確保・装備維持・野営・人との遭遇がプレイヤー自身の物語を生む。

## 中核ループ
1. 森・廃墟・禁域のいずれかで、生存者としてスポーン
2. 食料・水・医療品・資材・装備を探索（資源の枯渇・再出現を管理）
3. 時間・天候・飢え・脱水・気温・感染・出血に対応
4. 対戦や協力のため他の生存者と接触（将来のオンライン機能）
5. 拠点を構築し、物資を保管し、維持する
6. 死んだら手持ちを失い、別の生存者として始める。現地の遺体から回収する余地は残す

## 今回のPR — 第1マイルストーン
- 新規 `scenes/survival_world.tscn` をゲームの起動シーンへ切り替える。旧作の `scenes/main.tscn` は削除せず、資産の移植元として保護する
- シームレスに歩き続けられる一枚のマップ、森・廃墟・禁域、昼夜・雨
- 物資の探索・再出現、飢え・脱水・体温・出血・感染
- 感染者による追跡・近接攻撃、近接／弾薬を消費する遠距離攻撃
- 野外で包帯制作、建築した拠点の倉庫預け入れ・引き出し
- ゲーム内時間・生存状態・手荷物・拠点を `user://dopagaki_world_v1.json` へ保存
- 死亡すると手持ちを失い、Rで別生存者としてリスポーン
- **WAVE・時間制脱出・必須出撃メニューは新モードに存在しない**

## 第2マイルストーン（今回追加）
- 既存の狼の歩行素材、ミントの歩行素材、ちゅぶらの画像を新ワールドに使用。現段階は先頭フレーム中心の仮表示
- ミントが同行・近接補助攻撃。ちゅぶらが同行し、付近の物資を強調表示
- 既存7職業を職業名と得意武器として再利用。建築拠点の近くで1～7を押して切替。職業専用スキルは未移植
- 既存8種の武器名、レア度、攻撃力、耐久度を再利用。武器箱から取得→予備3枠→Vで切替
- 4部位の防具を探索で取得し、感染者の攻撃ダメージを軽減
- Jの射撃は装備・弾薬・向きが必要。マウス照準と左クリック攻撃にも対応。発砲音に感染者が反応する。Ctrlの静音移動は発見されにくい。Shiftの疾走はスタミナを消費
- 武器修理、拠点での武器保管／引き出し、死亡時の物資・武器・防具のドロップと遺体回収
- 武器・防具・遺体・物資コンテナ・拠点を保存。既存の出撃型旧ゲームの保存データは上書きしない

## 従来版との共存
- 旧ゲームは `scenes/main.tscn` から直接起動できる
- 旧セーブ（倉庫や装備）は新しい `user://dopagaki_world_v1.json` に自動移行しない。移行スクリプトを設計・検証する前に消去しない
- 既存のエクストラクション／WAVEのテストは旧シーンを指定して実行し続ける
- 新ワールドもまだ**1人用試作**。PvPや永続マルチが実装済みと宣伝しない

## 受け入れ条件
1. Godot 4.7.2 headless import と起動300フレームが成功する
2. 新シーンで歩行・感染者追跡・物資回収・消費・負傷・治療ができる
3. 拠点の預入と引出で数量が増殖せず、再起動後も保持される
4. 死亡時の手持ちロスト・再スポーン後の拠点残留が成立する
5. 旧 `scenes/main.tscn` の既存回帰テストを壊さない
6. テスト・プレイで旧データを無断削除しない

## 基本操作
WASD=移動、Shift=スタミナ消費の疾走、Ctrl=静音移動、マウス=照準、左クリック=武器攻撃、E=調べる／収納、G=取り出す、Space=近接、J=射撃、V=武器切替、B=持ち物、Z/X/Y=食料／水／包帯、C=包帯制作、F=拠点建設。建築拠点付近でH=装備武器保管、U=保管武器引き出し、1～7=職業変更。I=スクラップで武器修理。死亡後R=新しい生存者。
