# Discord への不具合報告・通知の設定(管理者向け)

使うチャンネルは **`#不具合報告`** の1つだけです。ここに、次の3つが流れます。

| 内容 | 誰が出す |
|---|---|
| 不具合報告(テスターのランチャーから) | ランチャー → 中継 → Discord |
| 「これから直す箇所」の宣言 / 「直しました」の報告 | `tools\discord-post.ps1` |
| 公開・保留・失敗の通知 | 自動配信(`publish.ps1`)が自動で出す |

## 手順 1:Discord の Webhook を作る
1. Discord で、`#不具合報告` チャンネルの設定(歯車)→ **連携サービス** → **ウェブフック** → **新しいウェブフック**。
2. 名前は何でも構いません(例: DOPAGAKI)。**ウェブフックURLをコピー** します。
   ※ このURLは**秘密**です。知っている人は誰でもこのチャンネルに投稿できます。チャットやリポジトリには貼らないでください。

## 手順 2:通知(宣言・報告・公開通知)を有効にする
あなたの PC に、次のファイルを作ります(リポジトリの外です)。

保存先: `C:\Users\<あなたのユーザー名>\.dopagaki-discord.json`

```
{"webhook": "ここに手順1のURL"}
```

これで、公開・保留・失敗の通知が自動で `#不具合報告` に出ます。
手動で投稿するときは次のようにします。

```
powershell -File tools\discord-post.ps1 -Kind plan -Message "Reaper の弾が消えない件を直します"
powershell -File tools\discord-post.ps1 -Kind done -Message "直しました(b23)。原因は…"
```

`-Kind` は `plan`(修正予定)、`done`(修正しました)、`warn`(要確認)、`info` です。

## 手順 3:テスターの不具合報告を Discord に届ける(中継)
ランチャーは、Webhook のURLを持てません(このリポジトリは公開で、URLが見えてしまうため)。
そこで、**Google Apps Script** の中継を1つ作ります。無料で、Google アカウントだけで作れます。

1. https://script.google.com を開き、**新しいプロジェクト** を作る。
2. 初期のコードを消し、`tools\relay\discord-relay.gs` の中身を貼り付けて保存。
3. 左の **プロジェクトの設定**(歯車)→ **スクリプト プロパティ** → **スクリプト プロパティを追加**:
   - プロパティ `WEBHOOK_URL` = 手順1のURL
   - (任意)プロパティ `TOKEN` = 好きな合言葉(省略すると `dopagaki-report`)
4. 右上 **デプロイ** → **新しいデプロイ** → 種類 **ウェブアプリ**。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - **デプロイ**(初回は権限の承認が出ます)。
5. 出てきた **ウェブアプリのURL**(`https://script.google.com/macros/s/.../exec`)をコピー。
6. `tools\launcher\launcher.gd` の `REPORT_URL` にそのURLを入れ、`LAUNCHER_VERSION` を1つ上げて公開します。
   (`TOKEN` を変えたなら、`REPORT_TOKEN` も同じにします)

これで、ランチャーの **REPORT BUG** が、Discord に直接届きます。
バージョン・説明・ゲームのログ(添付ファイル)が付きます。送信に失敗したときは、今まで通りメールの下書きが開きます。

## 注意
- 1時間に20件を超える報告は受け付けません(暴走対策)。
- 中継のURLは公開リポジトリに載るため、誰でも送信はできます。荒らされたら、手順3でデプロイを作り直して、URLを差し替えてください。
