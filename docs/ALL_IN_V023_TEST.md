# DOPAGAKI v0.23 — ALL IN 遊び方・実機テスト

## 目的
無双ビルドで強くなる楽しさと、「この戦利品で生還するか、あと1WAVE挑んで失うか」の意思決定を両立する。ゲーム内だけの装備・Gを対象とする。

## ゲームループ
1. WAVE1/2をクリアすると3つのランダム強化から1つ選べる。選択中はタイマー・敵・ドロップ寿命を停止する。
2. WAVE3以降をクリアすると「生還 [1]」か「ALL IN [2]」を選べる。未決定の間は敵が湧かず、世界が止まる。
3. 生還：手持ち・装備中の戦利品（初期武器以外）を倉庫に預け、冒険中の所持Gを安全な金庫に移す。次の冒険はLV1から。
4. ALL IN：次のWAVE用の3択強化に進む。選択後は12秒の休憩を挟み、次のWAVEへ。次のWAVEをクリアするまで帰還できない。
5. 死亡：その冒険の手持ち装備と冒険Gは失う。既に倉庫に預けた装備と金庫Gは維持される。

## 強化9種類（1種類最大3段階）
- 連射加速：攻撃速度+18%累積
- 破壊の力：武器ダメージ+22%累積
- 不屈の生命：最大HPと現在HP+35
- 疾風の足：移動速度+14%累積
- 弾幕増殖：発射時、左右に追加弾を1発ずつ（段階ごとにさらに増える）
- 貫通の刃：弾の貫通数+1
- 血の祝福：敵を倒すたびHP+3
- 連鎖爆発：敵撃破時に近くの敵へ範囲ダメージ
- 鋭い一撃：クリティカル率+6%

## 報酬・危険（表示される確定倍率）
| WAVE | ゴールド報酬倍率 | 追加の敵強化 |
|---|---|---|
| 1/2 | x1.0 | x1.00 |
| 3 | x1.5 | x1.00 |
| 4 | x1.8 | x1.12 |
| 5 | x2.3 | x1.24 |
| 6 | x3.0 | x1.36 |
| 7以降 | +0.4/WAVE、最大x5.0 | +0.12/WAVE、最大x1.75 |

※敵の通常のWAVE補正にも追加の敵強化が乗る。ゴールドは敵のドロップとWAVEクリア報酬が対象。装備は高WAVEほど落ちる機会とレア度が増加（固定の報酬倍率が装備個数を直接保証するわけではない）。

## 金庫・倉庫
- 装備保存: `user://dopagaki_stash_v1.json`（既存と同じデータ形式）
- 金庫G保存: `user://dopagaki_all_in_gold_v023.txt`（新設）
- 安全な金庫Gを使いたい場合は、挑戦開始前（WAVE0）にキャンプの倉庫で最大100Gずつ引き出す。引き出した後は冒険Gとなり死亡でロストする。
- 挑戦中（WAVE1以降）は従来の倉庫内個別預入を禁止し、戦利品を生還で確保する仕様に統一する。
- 倉庫が一杯なら勝手に装備を破棄せず、帰還失敗として選択画面にとどめる。出発前に整理しておくこと。

## 手動テストの観点
1. WAVE1とWAVE2後、3択強化が表示され、選択すると戦闘が正常再開する。
2. WAVE3後、生還と続行の2択が表示され、選択待ち中にWAVEや敵が進行しない。
3. WAVE3で帰還後、倉庫装備と金庫Gが保存されている。ゲームを再起動しても両方が残る。
4. 次の挑戦前に金庫Gを100G引き出せる。WAVE1以降は引き出せない。
5. ALL IN後、強化3択から1つ選ぶ。追加弾／撃破爆発／撃破回復の効果と上限を確認。
6. 続行したWAVE中の帰還を禁止し、死亡すると持ち出した装備・冒険Gだけを失う。
7. WAVE4以降は報酬と敵の危険が上がる。画面に表示した倍率と実際の計算が整合する。
8. リセット後は一時強化が消えるが、倉庫や金庫には影響しない。
9. 忍者、ヒーラー、ミント、ちゅぶら、LUMI SLOTを以前と同様に操作できること。

## CIについて
`tests/test_all_in_rules.gd` は WAVE倍率・生還ゲート・強化の定義を自動検証する。PRの Godot headless startup はシーンの読み込みと短時間起動までを検証する。画面遷移、入力による一連の帰還・戦闘・死亡やドロップ物理挙動は手動実機テストが引き続き必要。
