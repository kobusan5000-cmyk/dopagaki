DOPAGAKI v0.12 | テストプレイ用 / Windows / Godot 4.x 通常版
=========================================================

■ はじめに
Steam向け2Dトップダウン・ローグライトの開発途中の試作版です。
現時点では1人プレイ用。4人オンラインプレイは未実装です。
スロットは敵が落とす架空のゲーム内通貨のみ。現金・課金・換金はありません。

■ 0. 初回起動（Windows）
1. https://godotengine.org/download/windows/ でGodot EngineのWindows通常版を入手（.NET版は不要）。
2. GodotのZIPを右クリック→「すべて展開」。展開先のGodot実行ファイルを起動。
3. DOPAGAKI_v0.12_Fantasy_Waves_Merchant_Celtic.zipを右クリック→「すべて展開」。
4. Godotの「インポート」をクリックし、展開したDOPAGAKI_v0_12_Fantasy_Waves_Merchant_Celticフォルダ内のproject.godotを選択。
5. プロジェクトを開き、Godot右上の▶またはF5キーでゲームを実行。
   ノートPCではFn+F5が必要な場合があります。
6. 名前・色・アクセサリー・職業を選んでゲーム開始。
※前のv0.11フォルダに上書きせず、別フォルダに展開してください。

■ 今回のルール変更（v0.12）
- WAVEはタイマーで終了しません。決められた敵数をすべて倒した時だけクリアします。
- Wave 1は11体、Wave 2は15体、Wave 3は19体。以降増加（上限56体）。
- クリア後26秒の休憩。次の戦闘開始5秒前からカウントダウン音と数字が出ます。
- 初回は25秒の準備時間があります。休憩中は敵の追加出現なし。
- ノーダメージでWAVEをクリアすると追加12G＋メロンの種1個。連続撃破でもGを獲得。
- マップ面積はv0.11の約2.1倍。魔法の泉・ルーン石・妖精の光などの景観を追加。
- ミントの復活祭壇は安全キャンプの外、マップ南東の「月の祭壇」に移動。
  画面上部の方角と距離表示を参考に移動してください。

■ 新しい操作
WASD / 矢印: 移動
マウス: 狙う / 左クリック長押し: 攻撃
SPACE: 回避ジャンプ
E: 近くの対象を調べる（拾う、畑、料理、商人、スロット、ミント蘇生）
F: 畑に植える作物を切替（ニンジン→メロン→スイカ）
I: バッグ、1～5: ホットバーの装備切替
Q: 職業スキル（Lv5以降）
H/J: シチュー/スープを食べる
K/L: メロンジュース/スイカパフェを食べる
料理画面の1～4: シチュー/スープ/メロンジュース/スイカパフェを作る
商人画面の1～8: 商品を購入
M: 効果音・BGMのミュート
R: ゲームオーバー後に再挑戦

■ 武器商人「ルーン」
マップ中央寄り（初期位置から東へ約570）にテントがあります。近くでE。
1 炎のレア剣 50G
2 氷のレア弓 55G
3 星のエピック魔杖 135G
4 守護のレア鎧 55G
5 ニンジンの種×3 12G
6 メロンの種×2 42G
7 スイカの種×2 75G
8 キノコ×2 18G
※購入した装備は商人の右側に落ちます。近づいてEで拾ってください。
※所持品は5枠。満杯のときは先にIで整理。

■ レア農作物
敵が稀にメロン/スイカの種を落とします。近くでEで拾えます。
ニンジンは10秒、メロンは22秒、スイカは35秒で成長。
畑のそばでFで種を選び、Eで植え、育ったらEで収穫。
メロンジュース（メロン1）: HP+30、MP+25。Kで飲む。
スイカパフェ（スイカ1）: HP+60。Lで食べる。
ミントは従来どおり自律的に畑の管理・料理・戦闘をします。

■ 属性敵と武器
毒使い（Wave 3～）: 毒の弾。一定時間継続ダメージ。
氷使い（Wave 5～）: 氷弾。約1.1秒凍結、その後移動速度低下。
炎使い（Wave 6～）: 炎弾。火傷の継続ダメージ。
武器には烈火・氷霜・猛毒・星光・疾風などの追加特性があります。
攻撃は基本5%＋器用1ごとに2.5%の確率でクリティカル（最大50%）。
クリティカルダメージは通常の2倍。

■ 演出・BGM
通常時はオリジナルのケルト風ヒーリングBGM、戦闘時はオリジナルの戦闘BGM。
カウントダウン・クリティカル・WAVEクリアの効果音も追加。
BGM/SEはこの試作向けに波形合成したオリジナル音源です（既存曲の録音・コピーではありません）。

■ おすすめのテスト手順
1. F5でゲーム起動 → 25秒後のカウントダウン音を確認。
2. Wave 1の11体をすべて倒す → WAVE CLEARと26秒休憩を確認。
3. F1で商人にワープ → F3で100Gを追加 → Eで商人 → 武器/種を購入。
4. Fでメロンを選んで畑に植える → 22秒後に収穫 → 焚き火で料理。
5. F10を2回押す → ミントのハートをEで拾う → F4で月の祭壇にワープ → Eで蘇生。
6. Wave 3以降の毒使い、Wave 5の氷使い、Wave 6の炎使いを確認。
7. 器用を上げ、CRIT!（2倍ダメージ）と効果音を確認。

■ 不具合が出たら
Godot下部の「デバッガー」→赤いエラーメッセージのスクリーンショットを送ってください。
このZIPは静的な構造チェックをしていますが、Godot実機での動作確認は別途必要です。
