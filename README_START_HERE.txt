DOPAGAKI v0.8 — COMPANION / BIG MAP / CAMP BREAKS
==================================================
Godot 4.x (Windows 通常版)で開く試作ゲームです。4人オンラインはまだ未実装。
※ このZIPは実行ファイル（.exe）ではなく、Godotプロジェクトです。

【起動手順】
1. https://godotengine.org/download/windows/ からGodot EngineのWindows通常版（.NET以外）を入手。
2. Godotを展開・起動。
3. このゲームZIPも「すべて展開」し、中の project.godot を確認。
4. Godotの「プロジェクトマネージャー」→「インポート」→ project.godot を選択。
5. プロジェクトを開き、F5キーか右上の「▶」で起動。
6. キャラ名・色・帽子・職業を選んでスタート。

【操作】
WASD / 矢印       移動（カメラが追従します）
マウス            狙う
左クリック長押し   攻撃（戦闘ウェーブ中）
E                 近くの武器や防具を拾う
I                 持ち物画面（5枠）を開く
G                 畑で種まき/収穫
C                 キャンプの焚き火で料理メニューを開く
1/2（料理画面）     シチュー/スープを「作って保存」
H                 作っておいたシチューを食べる（HP +40）
J                 作っておいたスープを飲む（HP +25、速度上昇）
M                 音のオン/オフ
R                 ゲームオーバー後の再挑戦

【変更点】
・画面左上に「YOU HPバー」と「MINT HPバー」、主人公の頭上にもHPバーを追加。
・マップを大幅拡大。オオカミを追うカメラ、2か所のキャンプと10か所の畑、景観オブジェクトを追加。
・最初25秒の準備 → 戦闘48秒 → 休憩26秒 → 戦闘48秒…を繰り返す。
・休憩中は敵と敵の弾が消え、新しい敵は出現しません。休憩時に種+2、キノコ+1補給。
・作物は10秒で育つように短縮。料理は作り置き可能。
・通常敵の装備ドロップ率は合計約8%に削減（武器4.5%、防具3.5%）。
・通常敵より強いSTORM BRUTE、さらに3ウェーブ目以降は強敵NIGHT REAPERが出現。
・MINT（緑の帽子をかぶったキツネの料理人）が仲間。追従して魔法弾で援護、
  プレイヤーHPが低い時に回復、MINT自身のHPが減ると作り置き料理を食べて回復。
  MINTが倒れても約24秒後に復帰。

【テストキー】
F6     STORM BRUTE出現
F7     防具を出す
F8     LEGENDARY武器を出す
F9     NIGHT REAPER出現
F10    MINTにテスト用ダメージ（料理を食べる動作確認）

【MINTの料理テスト】
スタート後、キャンプでC → 1（シチューを作る）→ Cで閉じる → F10でMINTにダメージ。
数秒後、MINTがシチューを消費して回復し、「MINT ATE CARROT STEW!」と出ます。
※ 料理がない時や料理を作る前は食べられません。
