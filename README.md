# DOPAGAKI

Godot 4.7 の2Dサバイバルゲーム（開発中）。

**2026年11月：DayZ型のオープンワールド生存ゲームへ根本転換中。**

- **新しい起動シーン**: `scenes/survival_world.tscn`（生き延びることが目的。WAVE・強制脱出なし）
- **従来の試作**: `scenes/main.tscn`（出撃・脱出型。既存システム移植まで保護）
- [サバイバル転換の設計・進行状況](docs/SURVIVAL_REBOOT.md)
- [開発者向け](docs/開発者向け.md) / [テスター向け](docs/テスター向け.md)

## 現時点の新モード
WASDで探索し、Eで物資回収。食料・水・包帯を確保し、感染者から逃げて、生存する。Cで包帯制作、Fで拠点を建築、Eで収納、Gで取り出し。死亡したら持ち物を落とし、Rで新しい生存者になる。

このモードは**1人用の基本動作試作**。オンラインPvP、ミント・ちゅぶら、従来の装備・職業の統合はまだ作業対象。

## 配信の仕組み

```
開発者が Google Drive の共有フォルダに ZIP を入れる
   → 管理者が tools\publish.bat で確認して配信
   → GitHub が自動でビルドして新しい版(Release)を作る
   → テスターのランチャーが最新版に更新して起動
```
