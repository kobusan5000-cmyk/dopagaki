## 現時点の新モード
WASDで探索し、Eで物資回収。食料・水・包帯を確保し、感染者から逃げて、生存する。Cで包帯制作、Fで拠点を建築、Eで収納、Gで取り出し。死亡したら武器・防具・持ち物を落とし、Rで新しい生存者になる。Ctrlで静音移動、Shiftでスタミナを使って疾走、マウスで照準・左クリックで武器攻撃、Jで射撃（武器・弾薬が必要）、Vで予備武器に切替、Iで武器修理、建築拠点ではHで武器保管・Uで引出・1〜7で職業変更ができる。

このモードは**1人用の基本動作試作**。狼・ミント・ちゅぶらの表示／同行、旧8種の武器と7職業、4部位の防具、武器耐久・修理、拠点の武器収納、死亡後の遺体回収を実装した。**オンラインPvP、職業固有スキル、元の農業・料理・スロット、実際の建築レイド、フルアニメーションは未実装**。

## 配信の仕組み

```
開発者が Google Drive の共有フォルダに ZIP を入れる
   → 管理者が tools\publish.bat で確認して配信
   → GitHub が自動でビルドして新しい版(Release)を作る
   → テスターのランチャーが最新版に更新して起動
```
