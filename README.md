# DOPAGAKI

Godot 4.7 のアクションゲーム(試作)。このリポジトリにファイルを入れると、自動でビルドされ、テスターのランチャーが最新版に更新されます。

- 開発者向け: [docs/開発者向け.md](docs/開発者向け.md)
- テスター向け: [docs/テスター向け.md](docs/テスター向け.md)

## 仕組み

```
開発者がファイルをアップロード → GitHub が自動でビルド → 新しい「Release」ができる
                                                     → テスターのランチャーが最新版に更新して起動
```
